## Scripts

The following scripts are available:

- `dev`: Start the development server with turbo pack.
- `build`: Build the application for production and run the image optimizer.
- `serve`: Serve the application on port 80.
- `upload`: Upload the application to the server through ssh.
- `serve_https`: Serve the application on port 443 with SSL.
- `renovate_certificate_ssl`: Renovate the SSL certificate. Ensure that the 80 port is available
